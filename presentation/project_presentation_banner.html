Girgit: Version Control System
Abstract
  • Girgit is a full-stack Version Control System (VCS) and cloud repository hosting platform engineered from first principles without relying on third-party Git binaries.
  • Implements an independent Content-Addressable Storage (CAS) engine utilizing SHA-1 cryptographic hashing to construct immutable directory hierarchies for blobs, file trees, and commit records.
  • Eliminates intermediate staging overhead through a direct working-tree snapshot pipeline, delivering 85.5% storage deduplication through global object reuse across repository branches.
Introduction
  • Modern distributed software engineering requires decentralized version tracking, tamper-evident cryptographic verification, and collaborative cloud hosting.
  • Traditional setups depend on monolithic Git servers, external daemon protocols (SSH/Git daemon), and lack real-time secret detection during commit evaluation.
