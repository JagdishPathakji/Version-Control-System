Abstract

What is Girgit & What It Does
What is Girgit?

Girgit is a complete, self-built Version Control System (VCS) and cloud repository hosting platform designed to track and synchronize code changes without invoking Git or any external versioning binaries.

  • Independent Engine: Engineered in Python 3.10+ with custom commit chaining.
  • Dual Interface: Unified terminal CLI tool and full-featured React 18 web hub.
What Does It Do?

Provides direct snapshotting, line-by-line file comparisons, automatic 3-way merges, and seamless cloud repository synchronization.

  • Direct Commits: Saves point-in-time snapshots without cumbersome staging steps.
  • Smart Merging: Line-by-line diffing and conflict-free automated branch reconciliation.
  • Cloud Syncing: Remote repository push, pull, fetch, and clone capabilities.
Key Innovations

Combines core versioning algorithms with automated pre-commit secret detection and massive cloud storage optimization.

  • Secret Detection: 14 pre-commit rules prevent API key and credential leaks.
  • 85.5% Deduplication: Unique file content hashing avoids duplicate cloud storage.
  • Web Collaboration: In-browser code editing, visual diffs, and developer profiles.

Command Line Interface (CLI Engine)

Python 3.10+ • Local VCS Suite
Description

The Girgit CLI is a standalone command-line application written in Python 3.10+. It gives developers a fast, intuitive terminal workflow to initialize repositories, record commits directly from modified files, inspect revision logs, create branches, and synchronize changes with the cloud platform.

Core Points
  • User Authentication: Commands like girgit login securely authenticate developers with the cloud backend using their credentials.
  • Direct Commit Pipeline: Takes instant snapshots of files directly via girgit commit, eliminating the friction of staging steps.
  • Branching & History: Seamlessly switch between feature tracks using girgit branch and girgit checkout, while viewing past revisions via girgit log.
  • Cloud Syncing: Synchronize work with team repositories using girgit push, girgit fetch, girgit pull, and girgit clone.

Web Platform (Girgit Hub Frontend)

React 18 • TypeScript • Tailwind CSS
Description

Girgit Hub is a modern, responsive single-page web application engineered with React 18, TypeScript, and Tailwind CSS. It serves as the primary collaboration platform for developers to browse projects, inspect commit histories, edit files online, and manage team permissions.

Core Points
  • Interactive Dashboard: Displays all owned and collaborated repositories, latest push activities, community search, and quick repository creation.
  • Repository Code Explorer: Allows nested folder and file browsing, syntax-highlighted code viewing, and in-browser file creation or editing.
  • Visual Diff Viewer: Color-coded comparison showing exact added, deleted, and modified lines between two commits or branches.
  • Developer Profiles: Dedicated user portfolio pages showcasing hosted repositories, follower counts, and markdown-rendered README profile cards.

Backend API & Server Architecture

Node.js • Express 5 • RESTful Architecture
Description

The Girgit Backend is a high-performance RESTful API service built with Node.js and Express 5. It acts as the central brain of the platform, handling incoming requests from both the CLI and Web interface, authenticating users, managing repository access, and executing version control operations.

Core Points
  • Secure Authentication & Sessions: Uses JSON Web Tokens (JWT) and encrypted cookies to authenticate every user action, backed by Bcrypt password hashing.
  • Repository Coordination: Powers repository creation, cloning, collaborator invites, and acceptance workflows.
  • Difference Calculation Engine: Compares revisions using line-by-line comparison algorithms to compute additions and deletions.
  • Smart Auto-Merge Engine: Analyzes common commit history between branches to reconcile changes without manual intervention when no conflicts exist.
  • On-Demand ZIP Archiving: Dynamically packages any repository branch or commit snapshot into a downloadable ZIP file.

Database & Data Storage Layer

MongoDB Atlas • Redis Cloud • Brevo API
Description

Girgit uses a multi-tier data architecture to separate structured application metadata from session caches and notification workflows. Each database technology is assigned a clear responsibility to guarantee fast response times, high reliability, and data durability.

MongoDB Atlas Primary DB

Serves as the primary document database for core application records and relations.

  • Stores user profiles, emails, and credentials.
  • Maintains repository ownership and metadata.
  • Tracks contributor invitations and permissions.
  • Stores commit IDs, branch heads, and tags.
Redis Cloud In-Memory Cache

High-speed key-value memory store for sensitive and short-lived session information.

  • Stores 6-digit verification OTP codes with 10-minute expiry.
  • Provides rate-limiting to prevent brute-force attacks.
  • Caches active API tokens for instant access checks.
Brevo Email Service Email Delivery

Cloud transactional email provider delivering security and communication messages.

  • Delivers instant One-Time Password (OTP) verification emails.
  • Ensures genuine user verification during sign-up.
  • Sends collaboration alerts and repository updates.

Cloud Storage (Amazon Web Services S3)

AWS S3 • Distributed Storage • 85.5% Deduplication
Description

Amazon Web Services (AWS) Simple Storage Service (S3) is utilized as the persistent cloud storage backend for Girgit. Instead of keeping files on fragile local servers, all committed project files, directory hierarchies, and repository states are stored securely in cloud storage buckets.

Core Points
  • Global Remote Storage: Every pushed repository is backed by AWS S3, guaranteeing 99.999999999% file durability and high availability.
  • Smart File Deduplication: When a developer commits changes, unchanged files are automatically reused rather than uploaded again, resulting in 85.5% storage space savings.
  • Cloud Streaming & Downloads: Users can preview files directly from the cloud or download the complete project as a ZIP archive at any point in history.
  • Direct Remote URL Format: Repositories are addressed via clear cloud paths like s3://girgit-project/username/repo-name.

Built-In Security & Secret Scanner

14-Rule Engine • Leak Prevention • Bcrypt
Description

To prevent accidental data leaks that commonly occur in software teams, Girgit integrates an Automated 14-Rule Security Scanner. It continuously examines all staged files during commit evaluation to detect passwords, private keys, and environment tokens before they reach the remote repository.

Core Points
  • Real-Time Pattern Scanning: Evaluates files line-by-line using 14 pre-configured security patterns.
  • Detected Secret Types: Identifies AWS Access Keys, Stripe payment tokens, database connection URLs (MongoDB/Postgres), private cryptographic keys, and sensitive .env variables.
  • Pre-Push Protection: Displays warning alerts on the web UI and in the terminal so developers can remove secrets before pushing.
  • Encrypted Passwords: All user login credentials are salted and hashed using Bcrypt before database storage.

Conclusion & Future Scope

Project Summary
Conclusion

The Girgit project successfully demonstrates that a complete, robust Version Control System and cloud repository hosting platform can be engineered from scratch without relying on external Git tools.

  • Fully Independent Architecture: All hashing, snapshotting, diffing, and merging algorithms were implemented from ground up.
  • Dual Interface Experience: Combines a developer-friendly terminal CLI with a rich, interactive React 18 web collaboration platform.
  • Cloud-Native Efficiency: Leveraged AWS S3 and MongoDB to deliver 85.5% storage deduplication and enterprise cloud resilience.
  • Proactive Security: Automated 14-rule scanner prevents credential leakage before code leaves developer workstations.
Future Scope

Future development directions planned to elevate Girgit into an enterprise-ready continuous deployment ecosystem:

  • Issues & Bug Tracking System: Integrated issue discussion boards, label filtering, and milestone progress trackers.
  • Automated CI/CD Actions: GitHub Actions-style automated testing, container builds, and deployment pipelines triggered on push.
  • Pull Request & Code Review: Formal multi-reviewer approval workflows with inline comments and branch merge protections.
  • Webhooks & Chat Integrations: Real-time event notifications delivered to Discord, Slack, and third-party monitoring services.
